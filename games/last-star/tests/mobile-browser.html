This opt-in fixture checks the real game in a same-origin iframe. It sends synthetic PointerEvents with independent finger IDs and resizes the iframe to phone landscape dimensions. It is not a physical iPhone, Safari, Android device, or OS pointer-capture test. Browser screenshots and real-device play are separate verification steps.

Focused scenarios use the game's existing ?qa API to reset the run, remove enemies, seed item charges, and trigger death. The QA panel is hidden while measuring controls. Existing local save/settings values are restored after the run.
