## Artwork and provenance

Built-in imagegen created and edited the whole-character raster paintings. Source PNG bytes are preserved unchanged. The original four directional sheets remain in assets/hearthkin-*-v1.png; their exact prompts remain in PAINTED_HEARTHKIN_PROMPTS.json.

The new accepted sheets are in assets/work-v2/. Each of the 21 action IDs in work-actions.json has a source PNG. Six additional left-sw-*.png and left-nw-*.png sheets provide independently authored left-facing replacements for tool, combat and magic actions. No view is generated by runtime mirroring, and no limb rig is used.

Exact prompts, reference inputs, generated output paths, extraction requests and direction-correction attempts are preserved in provenance-v2/. work-art.js records the final source file and frame used for each action and view. WORK_ART_ANALYSIS.json records dimensions, true RGBA transparency and SHA-256 hashes. Earlier attempts remain available for comparison; final mappings determine which artwork is displayed.

The read-only atlas measurement tool finds transparent gutters and connected silhouettes. Canvas clipping excludes neighboring sprite fragments without rewriting artwork pixels. A constant scale and shared floor within each clip avoid enlarging the character as she crouches. Only the selected action's cropped frames are retained in the playback cache.

## Studio controls

Choose an action and direction, compare all four views, slow playback, scrub, or hold an individual painting. One-shot reactions hold their final pose; Replay restarts them and Repeat allows looping. Walking and loaded carrying support travel around the clearing. Ground guides and previous-frame ghosts help diagnose foot movement. Preview every action runs through the entire catalog.

These are complete initial action cycles for review, not a production release. Four-painting work cycles still have visible pose changes; tool contact, directional consistency, hand placement and return transitions should be refined with the user before integration. Frame captions describe the intended pose and are not a substitute for anatomical inspection. The original Study 01 files are archived under study-01/.
